# 🧑‍💻 Find Your Group: AI-Powered Hackathon Team Builder

A smart application designed to help hackathon participants quickly and effectively find compatible teammates based on their skills, goals, and interests.

---

## 🛠️ Tech Stack

- JavaScript
- React
- API/SDK

---

## 🚀 Getting Started (Local Setup)

```shell
npm install && npm run dev
```

## Planned features

- Database
- Hot-swap AI provider
- More options (student, professional, learner...)
- Hosted (separate groups, more filters)
- CSS + accessibility
